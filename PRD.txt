PRD: EDAS Decision Support System — Pemilihan Rumah
1. Tujuan
Bangun website sederhana untuk menghitung dan menampilkan hasil metode EDAS (Evaluation Based on Distance from Average Solution) pada kasus pemilihan rumah dengan 20 alternatif dan 8 kriteria.

Table

interface EDASResponse {
  av: number[];              // 8 nilai rata-rata
  pda: number[][];           // 20x8
  nda: number[][];           // 20x8
  sp: number[];              // 20
  sn: number[];              // 20
  nsp: number[];             // 20
  nsn: number[];             // 20
  as: number[];              // 20
  ranking: {                 // 20, urut dari rank 1
    rank: number;
    alternative: string;
    as: number;
    nsp: number;
    nsn: number;
  }[];
}

8. Engine EDAS (Backend — copy dari Colab)
Fungsi-fungsi yang harus ada di engine.py (sudah tervalidasi di Colab):
calculate_av(matrix) → av[8]
calculate_pda(matrix, av, types) → pda[20][8]
calculate_nda(matrix, av, types) → nda[20][8]
calculate_sp(pda, weights) → sp[20]
calculate_sn(nda, weights) → sn[20]
calculate_nsp(sp) → nsp[20]
calculate_nsn(sn) → nsn[20]
calculate_as(nsp, nsn) → as[20]
calculate_ranking(as, alternatives) → ranking terurut
Logic tipe kriteria:
Benefit: pda = max(0, (x-av)/av), nda = max(0, (av-x)/av)
Cost: pda = max(0, (av-x)/av), nda = max(0, (x-av)/av)
